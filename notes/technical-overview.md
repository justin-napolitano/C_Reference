This repository offers a collection of fundamental algorithms in C, including classic sorting, searching, and mathematical functions. It serves as a handy reference for implementing common algorithms in C.

### Key Features
- **Sorting Algorithms**: Selection Sort, Bubble Sort, Merge Sort, Quick Sort, Bucket Sort, Radix Sort, Insertion Sort, Counting Sort.
- **Mathematical Algorithms**: Fibonacci sequence, factorial, prime checking.
- **Utilities**: Palindrome checking, CSV parsing.

### Getting Started
To try this out, you'll need a C compiler (like `gcc`). Compile and run any program with:

```bash
gcc filename.c -o output
./output
```

Replace `filename.c` with the relevant source file.
